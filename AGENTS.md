# Agent guidelines

## Changelog

Never edit `CHANGELOG.md`. It is generated by release automation:
`.github/workflows/post-release.yml` runs the `changelog-from-release` action
against it, from release notes built out of merged PR titles and categorized by
`.github/release.yml`. Describe changes in the PR description instead.

## Public API consistency

When a visual primitive is exposed through multiple public surfaces, keep its
behavior and configuration consistent across all of them. For example, a
sparkline capability should cover table columns, standalone plot emitters, and
card regions. Document and test any intentionally narrower scope.
